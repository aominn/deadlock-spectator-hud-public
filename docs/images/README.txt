Documentation photographs — 0.6.0
Captured 2026-11-01 using the unmodified public 0.6.0 runnable package and game build 6839, Japanese UI, 1920x1080 replay window.
Recent replays were downloaded through the game's standard replay download UI. Three replays started successfully; the third failed during a mid-match seek. Published photographs use two successfully viewed matches only.

New images are cropped/resized JPEGs, not extracted game assets. Numbered panels are different regions of one actual frame, not a simultaneous synthetic HUD. No game values, icons or gameplay content were replaced. Mouse pointers are outside the selected crop. Drawing strokes were made with the real drawing feature and are demonstrations, not game events.
