Deadlock Spectator HUD 0.6.0 — Quick guide

SETUP
Close Deadlock. Extract the complete release ZIP, open HudManager.exe, select the
Deadlock/game/citadel folder containing gameinfo.gi, then Set up → Enable HUD → Launch game.
Windows 10/11 x64, Steam and Deadlock are required. Other runtimes are bundled.
Images are prepared from the installed game; missing images do not stop the other features.

WINDOW
Keep the manager open while spectating. Minimize to continue, or close to stop the
companion and analysis. To remove the HUD, close the game and choose Restore normal mode.
Closing the manager by itself stops the companion; use Restore normal mode to remove the MOD.

UPDATE
Close both the game and manager. Download the latest runnable ZIP from the
GitHub Releases page, extract to a new folder, and open that folder's HudManager.exe.
Follow the manager's prompts, enable the HUD and launch the game.
Newer versions retain settings and the previous version. Do not mix individual files.

HELP
Verify files checks the package. Refresh images prepares images again from your game.
Restore previous version uses the retained installation. Close the game before these operations.
If a game update breaks the display, restore normal mode and wait for a compatible HUD release.
Older replays may be incompatible with the current game. Some long seeks can exit the game. Leave live spectating before opening a replay.

LANGUAGE
Manager and drawing toolbar: Windows display language (Japanese, otherwise English).
HUD additions: Deadlock client language (Japanese, otherwise English).
The original game UI language is not changed. Unknown or ambiguous identities are not guessed.

DRAWING
Enable Drawing each time you open the manager. F8 is the default toolbar key and can be changed in the manager. Draw / Watch switches input.
Esc returns to game controls and keeps drawings. Changing apps keeps drawings too.
Normal mode, tool shutdown, a different match or a detected seek clears drawings.

Other MOD combinations are untested; problems caused by conflicts are outside the scope of support.

Unofficial spectator/replay tool. Not approved or supported by Valve.
See README.en.md and docs/STATUS.txt for coverage and remaining limitations.

If recovery is pending or an existing file prevents enabling the HUD, close the game, return to normal mode, then enable the HUD again. If recovery detects other changes, stop and keep the files rather than deleting them manually.
