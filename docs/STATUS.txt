Known limits
- Use with other MODs has not been tested. Display or functional problems caused by MOD conflicts are outside the scope of support.
- Long seeks in some replays may terminate the game.
- Drawing can reduce FPS. It does not pause live matches automatically.
- All heroes/effects, all live features, broader hardware, OBS capture methods, exclusive fullscreen and shrine physical left/right mapping have not been exhaustively verified.
- Published screenshots are game captures; they do not establish that a particular OBS capture method includes every UI element or drawn line. Check the actual broadcast setup before use.
- Old replays may be incompatible with the current game. Leave live spectating before opening a replay.

This is an unofficial spectator/replay tool, not a regular-play tool. Exit the game and select Restore normal mode before regular play. Closing the manager stops its companion but does not remove the installed MOD.
Game images, native UI originals, game fonts, generated VPKs, authentication, personal settings, logs and replays are not included in the runnable ZIP. Game assets are prepared from the user's installation. Compatibility identifiers and display-name mappings remain in the source.
Valve does not develop, approve or support this tool.
