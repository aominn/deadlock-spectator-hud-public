Deadlock Spectator HUD 0.7.10 public source.

Included: project source for the game HUD, Windows manager, replay and live parsers, and build tools. Automated regression tests, compatibility identifiers, display-name mappings, and third-party license notices are also included.

The executable ZIP is built separately. It includes the runtime dependencies and license notices. It omits development tests and harnesses, build intermediates, experiment files, logs, replays, settings, and credentials.

Initial setup prepares the required game images and UI resources from the user's local Deadlock installation. The public source and executable ZIP omit extracted game images, native UI originals, game fonts, and generated VPK files. Modifier mappings contain the identifiers needed by the parser.

The screenshots in docs/images illustrate the interface. See docs/images/README.txt for their sources and versions. Game content in those screenshots remains subject to its original rights. The project's MIT license applies to its own code.

See docs/BUILD.txt for the build procedure and docs/PORTABLE.txt for release checks.
